Data Governance & Telemetry Protection

Privacy Policy

Effective Date: November 3, 2026 • Domain: agropulse.farm

1. Scope of Collected Information

AgroPulse collects only the operational records required to run field irrigation and crop management: operator account credentials (username, registered email address, and salted password hash), capacitive probe telemetry (volumetric soil moisture, ambient temperature, relative humidity, and precipitation probability), field plot allocations, and pump actuation audit logs.

2. Geographic Coordinates and Weather Queries

When an operator initiates a live GPS weather query on the Weather Intelligence page, browser geolocation coordinates are used solely to request localized 7-day meteorological forecasts from the Open-Meteo service. Coordinates are not sold, shared with advertising networks, or tracked in the background.

3. Database Storage and Offline Caching

Farm records are stored in your configured PostgreSQL or local embedded H2 database instance. For field operations in low-connectivity rural areas, recent sensor readings and session tokens are cached locally in browser storage so operators can review last-known field status while offline.

4. Data Retention and Export Rights

Operators retain full ownership of all crop inventory records and sensor logs. Telemetry and plot registries can be exported to standard CSV format or deleted directly from the Crop Inventory workspace at any time.

5. Security Controls

Authenticated API endpoints require bearer token verification, and password recovery uses time-bound 6-digit verification codes. All pump actuation events are logged with operator attribution and timestamps.
